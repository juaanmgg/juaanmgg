## 🏆 Featured Project

### 🛡️ **TryHackMe Writeups & Pentesting Notes**
**Cybersecurity • Penetration Testing • Linux/Windows • Privilege Escalation**

A comprehensive and structured documentation of practical machine compromises demonstrating professional penetration testing methodologies for the eJPTv2 certification. 

**Key Audits Performed:**
*   **Kenobi (Linux):** SMB/NFS Enumeration, ProFTPD exploitation (mod_copy), and `$PATH` variable hijacking.
*   **Bounty Hacker (Linux):** Raw FTP interaction (Active Mode), SSH Brute-Forcing, and `tar` checkpoint abuse.
*   **Pickle Rick (Linux):** Web OSINT, Authenticated RCE (Command Injection), and Sudoers misconfigurations.
*   **Ice & Blaster (Windows):** Process migration (`spoolsv.exe`), in-memory credential extraction (`Kiwi/Mimikatz`), and CVE-2019-1388 (UAC Bypass).

**Arsenal:** Metasploit, Nmap, Gobuster, Enum4linux, Hashcat, John The Ripper, Hydra.
